# Global-Sales-Dashboard
Power BI Global Sales Dashboard
Global Sales Dashboard

This project is a Global Sales Dashboard created using Microsoft Power BI. It uses the Global Superstore dataset to analyze sales transactions from different countries around the world.

The dashboard includes sales analysis by City, State, Region and Market. It also shows shipping percentage by Ship Mode using charts, tables, maps and interactive slicers for Country, Region and Market.

This dashboard helps stakeholders understand sales performance, identify business trends and make better decisions. Data cleaning and visualization were performed using Power BI.
